# Belfast Unfolded

## About The Project:
Belfast unfolded is a tourist guide for the city of Belfast. The website offers sections such as history, attractions, travel advice and tourist packages.
The website provides useful information to users to plan their trips to Belfast.

## Features:
- Information about visiting Belfast including getting to and from and what to do while here
- A guide on the history of Belfast
- Package offers for tourist expriences
- Maps to allow extra guidance for the user

## How To Open This Project:
1. Download or clone this repository
2. If downloaded as a zip file, extract the zip file before opening, otherwise skip to number 3.
3. To open the website, open the project folder and open the "html" file
4. double click home.html to open the home page of the website
5. Explore the website through the nav bar. You can select whatever page you are looking for or use the search bar to search for it
